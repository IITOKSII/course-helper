Course Helper 19.0

Install once per course page reload.

  1. Refresh your course first to remove the older helper.
  2. Copy the code below. Open your lesson and press Ctrl + Shift + J for the Chrome Console.
  3. Paste the complete code and press Enter. The panel should show Course Helper 19.0.
  4. Click Start auto. Pause or Escape stops the helper.

Manual copy: click inside the code box, press Ctrl+A, then Ctrl+C.

If you are viewing this in ChatGPT, download the HTML and open it in Chrome. The code box remains usable even when scripts are blocked.
What to expect

The helper starts paused, finds accessible lesson frames, opens recognised information buttons, waits while you read, closes their pop-ups, and waits for the course timeline and Next control. It pauses at questions and if navigation cannot be confirmed.

For a different close icon, leave the pop-up open, choose Teach pop-up X, click the course X, and restart Auto. Other unrecognised activities need manual interaction.

If it stops, click Show diagnostics. Copy the selected report back into this chat. It includes control states, not your lesson text or login details.
