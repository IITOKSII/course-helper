Course Helper

Download this file and open it in Chrome. The ChatGPT file preview may block buttons and clipboard access.

Install directly. Click Start auto in the helper to advance after slide media ends. Text-only slides use the reading timer. Quizzes pause Auto.

  1. Open your course and the lesson.
  2. Click Copy helper code below, or click inside the code box and press Ctrl+A, then Ctrl+C.
  3. Return to the course. Press Ctrl + Shift + J to open Chrome’s Console.
  4. Paste the code and press Enter.

The helper runs only on the page where you paste it. Run it again after a full reload.

If Chrome blocks pasting, review the code below and follow the Console’s own instructions. If the course opens in a separate window, run it in that window.
